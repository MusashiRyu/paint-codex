# Architecture

## Component Table

| Component | Path | Responsibility | Notes |
| --- | --- | --- | --- |
| App shell | `src/app/App.tsx` | Composes the page header, list panel, export panel, search, filters, and results grid. | Header now uses split title treatment for the mobile-first visual refresh. |
| Paint matching UI | `src/features/browse/PaintCard.tsx` | Renders a paint and its equivalent matches. | Equivalent paints are now sorted by delta and filtered to close matches only. |
| Browse utilities | `src/features/browse/browse.ts` | Provides pure helpers for browse filters and match ordering. | `getTopMatches` accepts a maximum delta threshold. |
| Search UI | `src/features/search/SearchBar.module.css` | Styles the search input and autocomplete dropdown. | Dropdown stacking is raised above neighboring panels. |
| List management UI | `src/features/lists/ListsPanel.tsx` / `src/features/lists/ListsPanel.module.css` | Handles list creation, selection, rename, and paint removal. | Rename uses a draft value so spaces can be entered naturally; tab labels omit counts. |
| Export UI | `src/features/export/ExportPanel.module.css` | Styles markdown export controls and preview. | Shares the refreshed panel/button treatment. |
| Color utilities | `src/shared/lib/color.ts` | Exposes color conversion and delta threshold helpers. | Close-match threshold is centralized for reuse. |
| Global styles | `src/shared/styles/global.css` | Defines the app theme, typography, and shell layout. | Updated Warhammer-inspired visual treatment and header presentation. |
| Mobile tooling | `package.json`, `README.md`, `android/.gitignore` | Defines Capacitor build scripts and Android local-file hygiene. | Adds sync/build scripts and ignores local keystore files. |
| Tests | `src/test/PaintCard.test.tsx`, `src/test/markdownExport.test.ts` | Covers card rendering and markdown export expectations. | Locks in close-match filtering and plain paint-only markdown output. |
