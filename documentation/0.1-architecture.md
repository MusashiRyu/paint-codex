# Architecture

## Component Table

| Component | Path | Responsibility | Notes |
| --- | --- | --- | --- |
| App shell | `src/app/App.tsx` | Card/viewport layout, FAB, overlay state (search sheet, new list sheet), export trigger. | Lists-first redesign; previous browse/search/filter wiring removed. |
| App styles | `src/app/App.module.css` | Viewport dark-background, centered card, header, divider, FAB styling. | Card is full-screen on mobile; centered 390px card on desktop ≥500px. |
| Store | `src/app/providers/store.ts` | Persisted Zustand store; manages lists, selected list, and paint membership. | `PaintList` now includes `icon: ListIcon` and `color: string`; `createList` accepts optional icon/color with defaults; persist version bumped to 1 with migration. |
| List icon | `src/shared/ui/ListIconSvg.tsx` | Renders one of 8 SVG emblems (skull/star/shield/wing/crown/flame/moon/drop) for list tabs. | Pure presentational component. |
| Lists panel | `src/features/lists/ListsPanel.tsx` / `ListsPanel.module.css` | Tab bar (list selection + "+ New") and scrollable content (paints grouped by category, empty state, list header actions). | Replaced old accordion/rename UI. |
| Paint item | `src/features/lists/PaintItem.tsx` / `PaintItem.module.css` | Single paint row in the list view (swatch, name, brand/type, hex, remove button). | Edit mode shows an additional red "–" button on the left. |
| Search sheet | `src/features/search/SearchSheet.tsx` / `SearchSheet.module.css` | Bottom-sheet search overlay: text input, brand filter chips, fuzzy results with equivalents grid, ΔE pills, IN LIST badge, + add button. | Uses existing `search.ts` Fuse.js logic; opened by FAB or "+ ADD FIRST PAINT". |
| New list sheet | `src/features/lists/NewListSheet.tsx` / `NewListSheet.module.css` | Bottom-sheet for creating a list: name input, 8-icon emblem picker, 5-color banner picker, CREATE LIST button. | CREATE LIST is disabled until name is non-empty. |
| Export logic | `src/features/export/markdownExport.ts` | Generates markdown for a paint list with shop links. | Unchanged; triggered from App.tsx export handler. |
| Search logic | `src/features/search/search.ts` | Fuse.js fuzzy search over the paint catalog. | Unchanged; used by SearchSheet. |
| Browse utilities | `src/features/browse/browse.ts` | Pure helpers (brand list, color range filter). | Unchanged; `getUniqueBrands` no longer called from App. |
| Color utilities | `src/shared/lib/color.ts` | Color conversion helpers (hexToHSL, delta classification). | Unchanged. |
| Global styles | `src/shared/styles/global.css` | CSS variables (gold palette, text, state colors), base reset, font/scroll defaults. | Complete restyle; old shell classes removed; Cinzel + EB Garamond fonts. |
| Background images | `public/imagery/bg-page.png`, `public/imagery/bg-card.png` | Dark texture (page bg) and dark swirling abstract art (card bg). | Sourced from Claude Design mockup. |
| Tests | `src/test/` | Unit tests for store, search, export, and legacy UI components. | All 69 tests pass; legacy component files (BrandFilter, PaintCard, ResultsGrid, SearchBar, ExportPanel) preserved for test compatibility. |
